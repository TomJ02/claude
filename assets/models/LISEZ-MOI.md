# Modèle 3D personnalisé

Déposez ici un fichier **`monkey.glb`** pour remplacer le singe construit en code.
Il sera inclus dans l'exécutable généré par `npm run dist`.

Sans recompiler, vous pouvez aussi le déposer dans le dossier de données de
l'application (menu de l'icône → *Modèle 3D → Ouvrir le dossier du modèle…*),
qui est prioritaire.

Formats, orientation et noms d'animations attendus : voir la section
« Remplacer le modèle 3D par un fichier .glb » du README à la racine du projet.
